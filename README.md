# 🌐 Personal Portfolio Website

A modern and responsive **Personal Portfolio Website** built using **HTML, CSS, and JavaScript**. This portfolio showcases my skills, projects, certifications, achievements, resume, and contact information in a clean and interactive design.

---

## 🚀 Live Preview

> Clone the repository and open `index.html` in your browser or use Live Server.

---

## ✨ Features

- 👨‍💻 Professional Home Page
- 🙋 About Me Section
- 🛠️ Skills Showcase
- 📂 Projects Section
- 📜 Certifications
- 📄 Resume Download
- 📞 Contact Section
- 📱 Fully Responsive Design
- 🎨 Modern UI/UX
- ⚡ Smooth Animations
- 🤖 Interactive Chatbot
- 🌌 Particle Background Effects
- 🐙 GitHub Integration

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive Design
